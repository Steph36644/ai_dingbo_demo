## 1. 一句话定位

**本人自用的桌面 AI 盯播教练**：听本机正在播的直播声，实时转写，按滑动窗口对照「话术框架」，标出语速 / 节奏 / 内容问题，在应用内列表提示——让主播（或场边的你）及时知道「讲偏了什么」。

## 2. 背景与问题

直播中人很难同时「讲好」又「对照框架自查」。事后复盘太晚；企业合规巡检太重；提词器只负责滚稿，不负责判问题。

公开市场上几乎没有同时满足：**桌面环回 + 可切换流式 ASR + 可配置滑动窗口 + 对照本地话术框架做语速/节奏/内容督导** 的成品（详见 `docs/research/competitors.md`）。

## 3. 目标用户与场景

| 角色 | 场景 | 要什么 |
|------|------|--------|
| 主播 / 自播的你 | 直播进行中 | 不打断讲解的短、可执行纠偏信号 |
| 场边盯场（自用） | 听漏、听累 | 把「听 + 对照框架 + 标问题」自动化 |

**非目标用户（MVP）**：需要多直播间巡检、拉流固证、公网多租户的企业监管方。

## 4. 核心 Job

> 直播进行中，用近窗文稿对照预定框架，**及时发现并呈现「讲偏了什么」**。

不是：开播提醒、比价、GMV 中控、纯违禁词审核、提词滚屏。

## 5. 需求优先级

> 实现状态（2026-10-18）：**Must 与既有 Should 的主路径已交付**（M1–M3）。流式 ASR 可切换实现：默认本地 **FunASR sidecar**，**讯飞 RTASR 标准版**为第二 ASR。下面第 5.2 节第 4–6 条是本版新增，归 M4，代码尚未完成。

### 5.1 Must（没有就不是这个产品）

1. 本机**系统声卡环回**采音，可持续推流给 ASR
2. **流式 ASR 适配层**（可切换实现；直播中不热切换）。默认 **FunASR**，讯飞为第二实现
3. **滑动窗口分析**：默认每 **1 分钟**分析过去 **5 分钟**（均可配置）
4. 对照本地**话术框架文件**，产出三类问题：**语速 / 节奏 / 内容**
5. **应用内**问题列表 + 角标；每条问题可解释（时间窗 + 转写片段 + 触达的框架条目）

### 5.2 Should（MVP 可砍，砍了很痛）

既有第 1–3 条主路径已交付。第 4–6 条为 v0.2.0 新增，归 M4。

1. 问题附带一句建议动作（放慢 / 补卖点 X / 回到促单段）
2. 讲点覆盖勾选（`must_say` 已讲 / 未讲），与问题列表并存
3. 基础设置页：窗口时长、分析间隔。云端凭据只走讯飞（APPID + APIKey），经本机安全存储，不进前端明文。**通用「云 ASR 密钥」废弃**：没有适配器消费，和讯飞凭据并排易混；有效路径仅讯飞凭据。本版只改文档口径，设置页入口留到 M4 收敛
4. **云 ASR（讯飞）启用前须凭据就绪，否则不可开始**（未配置 APPID/APIKey 时开始按钮不可用，准备区写清原因）
5. 停止后**本场 JSONL 可回看**（最简 UI：本场问题 / 字幕摘要即可，不要求导出文件）
6. （可选）开始前 **ASR 健康预检**展示在准备区（FunASR / 讯飞）；失败时不可开始

### 5.3 Could（以后）

系统通知、直播流拉流、开播监测、应用内框架编辑器、语调/情感声学分析、场后复盘报告导出、多直播间、公网多用户、与「直播比价」数据打通。

### 5.4 明确不做（本 MVP）

开播监测、按 URL 拉流、比价、系统通知、公网多用户、企业断流/固证、无框架的「AI 自由点评」占满主路径。LiveNotes 不升格为正式能力，见 §5.5。

### 5.5 实验（不进正式 Should）

**LiveNotes 侧栏记事**已在界面出现，本版标为实验：渲染进程本地记事，不进规则引擎，也不进复盘。可折叠或日后移除，不作为验收项。

## 6. 播效对比：三类问题的 v0 定义

| 维度 | MVP 判定（规则引擎优先） | 说明 |
|------|--------------------------|------|
| **内容** | `must_say` 近窗未覆盖 → 漏讲；命中 `avoid` → 触雷；可选简单关键词/相似度跑题 | **最重要** |
| **语速** | 近窗有效字数 / 有效时长 → 字/分钟，对照 `pace.min`～`pace.max` | 可参考客服质检惯例 |
| **节奏** | 近窗静音占比、句密度、超长停顿或连珠炮 | 粗规则即可 |
| **语调** | **不进 MVP**；路线图标为 v2（声学/情感标签） | 避免虚指标 |

## 7. 话术框架（文件优先）

- 格式：本地 JSON（样例见 `frameworks/example-framework.v0.json`）
- 最少字段：`must_say[]`、`avoid[]`、`pace{min,max}`（字/分钟）
- 可选：`stages[]`（阶段）、`id` / `title`
- 应用内编辑器：**后置**；MVP 用外部编辑器改文件即可

## 8. 产品主流程

1. 打开桌面应用 → 加载话术框架文件
2. 选择环回设备 → 开始盯播
3. 实时字幕滚动（转写缓冲）
4. 每到分析间隔：取近窗文稿 → 跑规则 → 写入问题列表 / 更新角标与讲点覆盖
5. 停止盯播 → 本场问题仍可浏览。JSONL 已落盘（`sessions/<sessionId>/session.jsonl`）。最简回看 UI 见 §5.2 第 5 条，归 M4

## 9. 技术方案（初判）

| 模块 | 方案 |
|------|------|
| 桌面壳 | **Electron**（Mac / Windows；跨平台优先） |
| 采音 | 系统环回（Electron loopback / desktopCapturer 等） |
| ASR | **默认 FunASR sidecar**；**讯飞 RTASR 可插拔**（第二实现）；Key 用 Electron **`safeStorage`**。通用云 ASR 密钥废弃，有效云凭据仅讯飞 |
| 缓冲 | 带时间戳的滑动窗口文稿 |
| 分析 | 定时任务 + 规则引擎 v0；LLM 语义偏离可选后置开关 |
| 存储 | 本机会话与 JSONL 复盘；讯飞凭据走 `safeStorage` 独立密文文件。禁止明文密钥进仓库 |
| 仓库 | 需求对齐后再开；代码默认 Cursor 云端 + Grok |

与「直播比价」边界：本产品只管实时质检与提醒；价格/评价对比归比价项目。

## 10. 验收标准（怎样算有用）

1. 开盯后连续 ≥30 分钟不断采、不断字。**30 分钟真环回仍为人工验收**（仓库内只有 Fake 音频时钟单测，不算闭环）
2. 每条问题能对应：时间窗 + 转写片段 + 框架条目
3. 人工抽检：抽 10 个问题窗，≥7 条认为「确实该改」。仓库内尚无抽检记录，清单归 M4
4. 分析触发后，约 1～2 分钟内列表可见新问题。**漏讲要连续两个完整分析窗口才报，首条漏讲可能 >2 分钟**（默认 5 分钟窗时更久）。这是降误报的口径，不用「1～2 分钟」去卡漏讲首条
5. 无明显问题时不强行刷屏；角标 = 未读问题数

## 11. 里程碑（建议）

| 阶段 | 产出 | 状态 |
|------|------|------|
| M0 本文档 | PRD v0.1 + 框架样例 + 目录约定 | 完成（v0.1.0 已冻结） |
| M1 底座 | Electron 壳 + 环回 + ASR 适配（一家默认）+ 字幕缓冲 | **完成**（环回为 Electron loopback；原生 WASAPI 后置） |
| M2 分析 | 框架加载 + 语速/节奏/内容规则 v0 + 列表/角标 | **完成** |
| M3 打磨 | 建议动作、讲点勾选、设置项、自用稳定性；讯飞 RTASR 为第二 ASR | **完成** |
| **M4 体验硬化** | 见下 | 未开始（本版只定范围） |

### M4 体验硬化

**P0**

- 讯飞未配凭据时禁用开始，准备区写清原因
- 设置页密钥收敛：通用「云 ASR 密钥」标废弃或隐藏，只留讯飞一条有效云凭据路径
- 文档对齐（本 v0.2.0）

**P1**

- 开始前 ASR 健康预检（FunASR / 讯飞）展示在准备区；失败则不可开始
- 停止后本场 JSONL 只读回看（最简 UI）
- 真环回 30 分钟与 10 窗抽检清单（人工验收，不在本仓库自动闭环）

不进 M4：WASAPI 原生插件、可分发安装包、系统通知、应用内框架编辑器、直播中热切换 ASR、拉流 / 开播监测 / 多租户 / 比价。

## 12. 开放问题

以下三项在 v0.2.0 结案，不再作为开放项：

1. **默认 ASR**：本地 **FunASR sidecar**。云端第二实现是 **讯飞 RTASR 标准版**。直播中不热切换。见 SDD ADR-005 / §2.1。
2. **节奏阈值**：以 SDD §9.3 与代码里的 `RHYTHM_DEFAULTS` 为准，PRD 不另写一套数字。
3. **结束后落盘**：已写本地 JSONL（`sessions/<sessionId>/session.jsonl`）。应用内最简回看仍是 M4，不是开放问题。
