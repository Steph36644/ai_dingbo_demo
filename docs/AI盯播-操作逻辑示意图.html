AI盯播 · 操作逻辑示意图

v1.0.0 · 听本机直播声 → 转写 → 对照话术框架 → 告诉你「讲偏了什么」 · 只做抖音直播 · 内容盯播，不是 GMV 总控

一、端到端主流程 开播前 → 复盘，五步闭环

STEP 1

准备 · 开播前

加载话术框架（必讲 / 触雷 / 语速 / 阶段）· 选音源 · 选 ASR · 健康预检
预检失败 → 不可开始

STEP 2

开始盯播

环回采音（PCM）→ 流式转写 → 字幕成句展示（标点 + 800ms 静音断句）

STEP 3

盯播循环

每 1 分钟分析近 5 分钟：语速 / 节奏 / 内容 → 问题卡 → 中控处置

STEP 4

停止落盘

JSONL 写入 sessions/<场次>/
写盘失败 → 保留内存并提示

STEP 5

只读复盘

字幕摘要 + 问题卡（历次证据展开）· 场次目录 · 再盯一场不删文件

二、盯播中的核心循环 引擎只跑一套，双端只是投影

盯播引擎 · 主进程是唯一真相，任何界面不跑第二套规则
环回采音本机正在播的声音
ASR 转写FunASR / 讯飞
滑动窗口近 5 分钟文稿
规则引擎内容 · 语速 · 节奏
问题卡指纹聚合 · 带证据
投影 SessionProjection阶段 · 角标 · 建议 · 健康
↻ 每 1 分钟重复一次分析（窗口 5 分钟 / 间隔 1 分钟，可在设置调整）
Control · 中控盯播台可操作
  • 问题时间轴 + 转写证据 + 框架命中
  • 讲点覆盖（必讲已讲 / 未讲）
  • 处置：阶段切换 · pin · dismiss · 已读
  • 品备注 · 直播笔记（旁路记录）
  • 抬头屏控制 · 开始 / 停止 · 设置 · 回看
  • 底部状态栏：状态 / 时长 / 落盘 / 未读
Stage · 抬头大屏只读
  • 当前阶段（大字）
  • 未读角标（数字）
  • 至多一条建议（pin 可盖过自动选）
  • 健康点（进行中 / 不稳定 / 已停）
  • 成句字幕流（底部对齐）
  • 没有设置、密钥、时间轴、JSONL
同一份投影 ↓ 不同带宽：中控看「为什么」，大屏看「怎么办」

三、窗口语义与边界 什么时候谁在、谁关

打开抬头屏Control 显式选屏 → 窗口（排练）或全屏；全屏不占 Control 所在屏
关 Stage / Esc会话继续，字幕和问题照常更新
停止 / 关 Control会话结束，Stage 一并拆掉，不留孤儿大屏
显示器断开Stage 关、会话在，提示「抬头屏断开，盯播还在」
M6 · 信号区（空位）推流 / 发券信号：出站前必须人工确认 — 本版不实现
M7 · 可选闭麦（空位）avoid 命中仍只提醒；闭麦默认关 — 本版不实现
